# .gitignore

Use .gitignore templates:

- [.gitignore templates](https://github.com/github/gitignore)
- [.gitignore.linux](https://github.com/github/gitignore/blob/main/Global/Linux.gitignore)
- [.gitignore.macos](https://github.com/github/gitignore/blob/main/Global/macOS.gitignore)
- [.gitignore.windows](https://github.com/github/gitignore/blob/main/Global/Windows.gitignore)
- [.gitignore.node](https://github.com/github/gitignore/blob/main/Node.gitignore)
- [.gitignore.python](https://github.com/github/gitignore/blob/main/Python.gitignore)

Add .gitignore templates to .gitignore:

```bash
cat .gitignore.node .gitignore.python >> .gitignore
```
